# 🛡️ URL Phishing Analyzer (Prototipo)

Una herramienta en Python diseñada para evaluar enlaces y detectar posibles indicadores de phishing, desarrollada como prototipo académico para la materia de **Sistemas Colaborativos**.

---

## ⚠️ Aclaración Importante / Descargo de Responsabilidad

> **Nota:** Este software es **únicamente un prototipo con fines educativos y de demostración académica**. No es un sistema de seguridad infalible ni reemplaza a un antivirus o motor de análisis profesional. Se diseñó como un ejemplo práctico para entender la estructura de las URLs maliciosas y fomentar buenas prácticas en entornos colaborativos.

---

## 📌 Descripción del Proyecto

En el contexto de la materia **Sistemas Colaborativos**, este desarrollo acompaña a un sitio web informativo en Google Sites para coordinar, documentar y concienciar sobre la seguridad digital en la comunicación grupal y la detección de amenazas cibernéticas.

La herramienta evalúa parámetros básicos dentro de la sintaxis de una URL para alertar sobre patrones comúnmente asociados con ataques de phishing (como el uso abusivo de caracteres, direcciones IP directas, acortadores de enlaces o dominios falsificados).

---

## 🚀 Funcionalidades del Prototipo

* 🔍 **Análisis de sintaxis:** Examina la estructura del enlace ingresado.
* ⚠️ **Detección de indicadores de riesgo:** Identifica anomalías o patrones potencialmente sospechosos.
* 📊 **Evaluación demostrativa:** Devuelve una alerta previa indicando si el enlace cumple con criterios típicos de phishing.
